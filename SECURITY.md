# Security policy

Please report vulnerabilities privately, either through GitHub's **Report a vulnerability** button on this repository (Security tab) or by email to hello@salchimail.com with `security` in the subject. Do not open a public issue.

Include the version (`salchimail-local version`), your platform and the steps to reproduce. We aim to reply within 5 working days.

Only the latest release is supported. Problems in the SalchiMail API itself are also welcome at the same address.
